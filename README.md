# samokat-analysis
Анализ данных заказов сервиса Самокат студента Осадчая Е О

# Описание проекта
Анализ продаж товаров по категориям и подкатегориям за 13.01.2022.

# Цели анализа
1. Определить самую ходовую товарную группу
2. Построить распределение продаж по подкатегориям
3. Рассчитать средний чек на 13.01.2022
4. Проанализировать долю промо в категории "Сыры"
5. Провести ABC-анализ по сумме и количеству продаж

# Данные
- `orders.xlsx` — данные о заказах
- `products.xlsx` — справочник товаров

# Технологии
- Python
- pandas, numpy, matplotlib, seaborn
- Jupyter Notebook

# Запуск
```bash
# Клонировать репозиторий
git clone https://github.com/твой-ник/samokat-data-analysis.git

# Установить зависимости
pip install -r requirements.txt

# Открыть ноутбук
jupyter notebook notebooks/analysis.ipynb
